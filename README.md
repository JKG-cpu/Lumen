# Lumen
A game built in python that revolves around light!

# Installation

1. Clone the repository
```bash
git clone https://github.com/JKG-cpu/Lumen.git
cd Lumen
```

2. Install dependencies
```bash
uv sync
```

3. Run the game!
```bash
uv run lumen
```

# How to play

After installing, you can use these controls to light up the bulb!

LEFT / RIGHT ARROW: Controls the flashlight
CURSOR + A / D: Moves a mirror ***(THE CURSOR MUST BE HOVERING OVER IT)***
